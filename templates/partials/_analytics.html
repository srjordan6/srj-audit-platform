Local dev (127.0.0.1 / localhost) and any preview host stay clean, so dev traffic never pollutes the analytics properties. 2. Consent gate. GA4 cross-domain linking: the domains list below must be identical on every SRJ property. Cross-domain linking is not one setting — each property has to name every partner, or a visitor arriving from a site missing from this list starts a new unattributed session and the funnel is lost in that direction. Do not shorten it to "the ones this site links to". theworldofai.org and srjconsultingservices.com shipped this identical four-domain list on 2026-07-31. CONSENT MODEL ------------- GA4 uses Google Consent Mode v2. All four consent signals default to `denied` before the config call, so the tag loads but stores nothing and sends only cookieless pings until the visitor accepts. On acceptance the signals are updated to `granted` and full measurement begins. Clarity, StatCounter and LinkedIn Insight have no consent-mode equivalent, so they are not loaded at all until acceptance. They register through window.srjConsent.onGrant() and are injected only if and when consent arrives. Both
